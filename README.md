# Student Management System

A simple Student Management System developed using C.

## Features

- Add Student
- Display Students
- Search Student
- Update Student
- Delete Student
- Duplicate Roll Number Detection
- Subject-wise Grades
- Total and Average Calculation
- File Handling

## Concepts Used

- Structures
- Functions
- Arrays
- Loops
- Conditional Statements
- File Handling
- Searching

## Language

C
